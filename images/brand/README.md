# CodeQuiz identity — approved direction 03

The wordmark is a custom set of geometric letter paths with cut corners. The three ascending bars refer to progress through a practice session. These SVGs contain no fonts, raster images, scripts or external dependencies.

- codequiz-logo.svg: dark wordmark with Forest-green symbol, transparent background.
- codequiz-wordmark.svg / codequiz-wordmark-light.svg: standalone dark/light lettering.
- codequiz-mark.svg / codequiz-mark-light.svg: standalone green/light symbol.
- favicon.svg: high-contrast small browser icon.

The light assets are used on the existing dark sidebar. The mobile header uses the same assets at a smaller size; the narrowest layout shows the symbol alone. The rest of the site's design is retained.
